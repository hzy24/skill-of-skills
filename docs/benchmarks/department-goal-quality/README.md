# 部门目标完成质量：A / B / C 对比测试

这是一项基于 InsightEval 第 38 题的单题探索性测试：材料基本完备，用户用日常语言提出管理分析需求，分析方法由 Agent 选择。以下数据均为三次独立测试的平均结果

## 测试结果

| 任务 | A：直接交办 | B：匹配专业技能 | C：SoS |
| --- | ---: | ---: | ---: |
| 部门目标完成质量 | 20.31 | 20.55 | **24.82** |

表中分数为 InsightEval 本地 ROUGE-1 best-match 洞察 F1 × 100，越高表示与参考洞察的文本匹配程度越高。原始未取整结果见 [scores.csv](scores.csv)。

本题 C 比 A 高 **4.51 分**，比 B 高 **4.27 分**。

## 任务与组别

用户需求：

> 老板想知道各部门的目标完成得怎么样，哪些地方值得学习、哪些需要改进。附件是目标台账，帮我准备一份管理分析。

输入为公开基准中的目标台账 `data_38.csv`，实际包含 499 行，涉及部门、优先级、完成度、目标门槛及达标标志等字段。

- **A：直接交办。** 普通元景任务，不使用 SoS，允许系统选择已有能力，并非禁止技能的纯原生组。
- **B：匹配专业技能。** 使用同一需求和附件，提供与 C 对齐的 analyze、validate-data、docx、xlsx 专业能力；不提供 C 的方案。
- **C：SoS。** 按SoS的工作流，生成plan后执行与交付。

各组使用相同 DeepSeek 配置，每组运行三次。C 的规划与确认执行属于其工作流差异，三组并非逐字相同的完整提示词。

## 评分方法

以最终交付 Word 报告的正文段落及有实质内容的表格行为评分来源；按同一流程忠实提取、英译，再与原始英文参考洞察计算 ROUGE-1 best-match Recall、Precision 和 F1。排除标题、制作说明等非业务内容，不从规划或工作簿额外挖掘洞察。

| 组别 | Recall | Precision | F1 | 保留洞察数 |
| --- | ---: | ---: | ---: | ---: |
| A | 0.2518 | 0.1702 | 0.2031 | 35 |
| B | 0.2462 | 0.1763 | 0.2055 | 35 |
| C | 0.2469 | 0.2495 | 0.2482 | 31 |

- 受测 SoS 版本为 1.0.0 发布包。
