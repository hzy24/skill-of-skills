# 部门目标完成质量：A / B / C 对比测试

这是一项基于 InsightEval 第 38 题的单题探索性测试：材料基本完备，用户用日常语言提出管理分析需求，分析方法由 Agent 选择。

## 测试结果

| 任务 | A：直接交办 | B：匹配专业技能 | C：SoS |
| --- | ---: | ---: | ---: |
| 部门目标完成质量 | 20.31 | 20.55 | **24.82** |

表中分数为 InsightEval 本地 ROUGE-1 best-match 洞察 F1 × 100，越高表示与参考洞察的文本匹配程度越高。原始未取整结果见 [scores.csv](scores.csv)。

本题 C 比 A 高 **4.51 分**，比 B 高 **4.27 分**。这是单题、单次结果，不代表整体任务成功率或稳定提效。

## 任务与组别

用户需求：

> 老板想知道各部门的目标完成得怎么样，哪些地方值得学习、哪些需要改进。附件是目标台账，帮我准备一份管理分析。

输入为公开基准中的目标台账 `data_38.csv`，实际包含 499 行，涉及部门、优先级、完成度、目标门槛及达标标志等字段。

- **A：直接交办。** 普通元景任务，不使用 SoS，允许系统选择已有能力，并非禁止技能的纯原生组。
- **B：匹配专业技能。** 使用同一需求和附件，提供与 C 对齐的 analyze、validate-data、docx、xlsx 专业能力；不提供 C 的方案或答案。
- **C：SoS。** 先选专业能力并生成方案，确认后执行与交付。

各组使用相同 DeepSeek 配置，每组运行一次。C 的规划与确认执行属于其工作流差异，三组并非逐字相同的完整提示词。

## 评分方法

以最终交付 Word 报告的正文段落及有实质内容的表格行为评分来源；按同一流程忠实提取、英译，再与原始英文参考洞察计算 ROUGE-1 best-match Recall、Precision 和 F1。排除标题、制作说明等非业务内容，不从规划或工作簿额外挖掘洞察。

| 组别 | Recall | Precision | F1 | 保留洞察数 |
| --- | ---: | ---: | ---: | ---: |
| A | 0.2518 | 0.1702 | 0.2031 | 35 |
| B | 0.2462 | 0.1763 | 0.2055 | 35 |
| C | 0.2469 | 0.2495 | 0.2482 | 31 |

## 结果边界

- 这是 2026 年 11 月 1 日整理的历史 ABC 实验，受测 SoS 版本为 **v1.5.0-rc.1**；不是当前 1.0.0 发布包的独立认证，也不是后续文案回归测试的分数。
- 本题属于已接触过的回归题，每组一次，不能推导统计显著性或广泛泛化能力。
- C 交付了业务附件，但当时的执行登记和实质收尾仍有缺失；业务报告得分与流程完成情况分开评价。
- 文本匹配分数不是业务正确率，受表格表达、英译和提取粒度影响；参考洞察第 8 条存在已核实的源数据冲突，主分仍保留原始参考答案计算。
- 此处单独展示部门题，不代表三题总体结果。原三题实验中 C 的工单题规划失败；包含失败的三题均值为 A 15.18、C 13.74，B 该题跳过。
