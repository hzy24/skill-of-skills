# 专业能力发现与安装

本版新能力检索统一使用腾讯 SkillHub（https://skillhub.cn）。Claude SkillHub 和元景市场检索暂时停用；已安装的专业能力仍参与适配比较。

首次规划的检索、原文获取和候选登记统一使用 [flow.py](planning.md)。以下底层接口用于旧版任务兼容及执行阶段安装；新任务不手填 proposal、name 或 hash。

## 实际搜索与选型

按 find-skills 的思路，先提取任务意图、领域和具体判断方法，生成 2–4 个中文专业关键词。领域同义词、专业方法名分别查询；避免把整段用户需求作为唯一查询。已安装专业能力与检索候选一起比较。用户熟悉专业术语时直接采用其术语扩展检索。

新任务通过 flow.py search 使用腾讯官方 `/api/v1/search`。以下独立命令保留给旧任务兼容：

```sh
python <skill>/scripts/search_skills.py '<领域方法中文词>' '<中文领域或岗位词>' --task-dir <任务目录> --out <任务目录>/skill-search.json
```

程序记录每次请求状态、耗时并缓存，按 slug 去重。新任务先按搜索相关度召回，再根据业务问题重排；搜索接口 score 只表示检索排序信号，不作为专业质量评分。下载量、收藏数用于同等适配候选之间的比较。只发送专业关键词，业务附件和内部数据留在当前任务。

新任务每轮最多四词、每词最多五十项，三轮最多十二次搜索请求；模型只接收前十二条短摘要。category 是分类排序偏好，其他分类的相关专业技能仍保留。核读最多三个可读取的核心候选，来源失败另用替补名额，总获取次数最多六次。规划不再以五分钟思考时间截断下载；每个网络请求与候选读取保留独立超时。具体余量由 flow.py 返回，旧任务沿用原协议。

读取候选原文后，以本任务的核心判断筛选：方法提供哪些判断步骤、适用条件、重点对象和检查依据？这些方法是否适用于现有材料？把结论写入已有 fit_reason / input_fit，再按方法组织委托。名称、领域标签与通用分析流程只用于召回。一次关键词没命中就换词继续；接口错误保留诊断并尝试本轮其他具体候选，不据此改选通用能力或断言市场缺少方法。

## 读取原文与准备安装

腾讯候选由官方版本和文件接口直接读取，无需它具有 GitHub 仓库：

```sh
python <skill>/scripts/acquire.py inspect-tencent --task-dir <任务目录> --slug <搜索返回的slug> --reason '方法适配理由' --solves '解决的具体判断' --dependencies '实际依赖' --license '原文许可信息或待核实'
```

程序读取详情、固定版本文件清单及 SKILL.md，逐文件记录大小和 SHA256，返回 method_file、proposal、proposal_hash。此时只读取方法；用户授权后才安装完整文件清单。单文件接口支持最大 1 MiB，方法入口读取上限 256 KiB；包上限 10 MiB、100 文件。下载使用官方文件接口及核实的腾讯对象存储域名。

首次规划通过 flow.py inspect / section / resource 获取原文与实际方法目录。原文的中文名称、BOM 和 CRLF 换行均按原始身份解析；内容不改写，固定版本与哈希仍逐项核对。按任务契合程度和实际方法筛选，再比较下载量、适用条件和使用成本。

## 方案中的安装提案

业务草案 skills 填 origin="external" 和 proposal 路径。程序将提案嵌入 plan.json，HTML 详情展示：

- 准确技能名、腾讯 SkillHub 真实详情链接、固定版本。
- 为什么选择、实际方法优势、解决的具体问题与未覆盖部分。
- 下载字节数、文件数量和技能目录；运行依赖的额外下载、权限另列。
- 安装范围及待用户确认状态。大小、许可或必要依赖未核实时，先补齐再安装。

聊天简短提出具体请求，例如：“建议安装 X 来做条款交叉核对，技能文件共 86 KB，来源和理由已放在方案里。是否同意安装 X？”用户无需填写协议。普通“按方案执行”、保存方案、泛泛同意使用专业能力均不代表接受新安装。已有针对同一版本和范围的明确授权时可沿用，不重复询问。

用户拒绝时保留方案，寻找当前权限内的已安装能力，或等待用户调整；不自动降级。

## 获准后安装

```sh
python <skill>/scripts/acquire.py install <proposal.json> --task-dir <任务目录> --proposal-hash <返回值> --evidence '用户针对该技能的实际安装授权原话'
```

只下载批准的文件清单，逐文件核对大小与腾讯文件 SHA256；总上限 10 MiB、100 文件、120 秒。依赖单独核对授权，不执行远程脚本。失败清理临时目录；内容或版本变化须重新提案。安装到任务的 .sos-installed/。读取方法和必要配套资源后用 execute.py ready 核验，不手工修改 readiness。

## 用户改变任务后的新一轮

用户明确改变范围且需要重新选型时，保留当前方案、授权和成果，在新的修订任务目录以 `init --new-request 用户本次变更原话` 启动一次规划。新目录记录原方案路径、版本和用户变更依据；安装提案重新展示。单纯检索失败或超时不能重命名目录续搜。

## 执行边界

脚本约束经过其入口的获取和安装。Skill 无权拦截宿主直接发起的网络命令，也不能认证宿主转述的用户身份。真实验收需核查工具轨迹；绕过入口、无授权安装或来源错标均判本次失败。
