# Sources and acknowledgements

This package contains no bundled third-party skills. The discovery adapter is an original implementation using the documented Tencent SkillHub public API. Its retrieval workflow was informed by the public find-skill-skillhub instructions: task interpretation, multilingual query expansion, deduplication and relevance review.

- [Tencent/skillhub: discovery workflow](https://github.com/Tencent/skillhub/tree/main/skills/find-skill-skillhub)
- [Official search API](https://github.com/Tencent/skillhub/blob/main/docs/api/skills.md)

Earlier versions included selected resources from anthropics/knowledge-work-plugins, anthropics/skills and obra/superpowers. Those resources have been removed; this version retains the project's orchestration and review code.
